# Personal Portfolio

Personal portfolio website of **Fatimah Zahraa**, created for **Assignment-1 of Full Stack Development** as part of B.E. Computer Science and Engineering.

It is a single-page, responsive portfolio website showcasing my profile, education, technical skills, certifications, services, projects, achievements, and contact information.

## Technologies Used

| Technology            | Used for                                                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **HTML5**             | Semantic structure using header, nav, main, section and footer, along with lists, tables, links, images and forms |
| **CSS3**              | Cherry red and white theme, CSS variables, Flexbox, Grid, typography and responsive media queries                 |
| **Bootstrap 5**       | Navbar, grid system, cards, forms, buttons, tables, alerts and responsive components                              |
| **JavaScript (ES6+)** | Variables, functions, arrow functions, arrays, objects, loops, conditions, DOM manipulation and event handling    |

## Sections

* **Home** – Introduction, tagline, profile image, social links and navigation buttons
* **About Me** – Personal introduction, learning journey and key statistics
* **Skills** – Development, web technologies, AI/ML and creative design skills
* **Education & Qualifications** – Academic background, certifications and additional learning
* **Services** – Web Development, AI & Machine Learning, and Creative Design
* **Projects** – Selected projects including Palm Pay, Brain Tumor Detection and Real Estate AI Agent
* **Achievements & Certifications** – Professional certifications, courses and learning achievements
* **Contact** – Email, GitHub, LinkedIn and contact form

## Features

* Fully responsive layout for **mobile, tablet and desktop**
* Light mode / dark mode toggle
* Responsive navigation bar with mobile menu
* Interactive project filtering
* Dynamic project count
* Client-side contact form validation
* Success and error messages for form submission
* Scroll-to-top button
* Active navigation link based on the current section
* Bootstrap components and responsive grid
* Accessibility features including semantic HTML, form labels, descriptive image alt text and navigation support
* Modern cherry-red and white visual theme
* Interactive JavaScript elements using DOM manipulation and event handling

## JavaScript Features

The website demonstrates JavaScript ES6+ concepts including:

* Variables and data types
* Functions and arrow functions
* Arrays and objects
* Conditional statements
* Loops
* DOM manipulation
* Event handling
* Light/dark theme switching
* Mobile navigation
* Project filtering
* Contact form validation
* Dynamic UI updates
* Local storage for theme preference

## Responsive Design

The portfolio uses **CSS3 media queries and Bootstrap's responsive grid system** to adapt the layout to different screen sizes.

The website has been designed for:

* Desktop
* Laptop
* Tablet
* Mobile devices

## Accessibility

Accessibility considerations include:

* Semantic HTML5 elements
* Alternative text for images
* Labels and placeholders for form fields
* Accessible navigation links
* ARIA labels for icon-only buttons/links
* Keyboard-friendly interactive elements
* Responsive text and layout

## How to Run

To run the portfolio locally:

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
